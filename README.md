## 🚀 Proyectos

### 📈 Laboratorio 1: Gráficos y Visualización con Python

**Exploración del Capítulo 9 "Gráficos y visualización" del libro _Python for Data Analysis, 3rd Edition_ de Wes McKinney.**

- **Ubicación:** [`proyectos/lab1/Lambda/`](./proyectos/lab1/Lambda/)
- **Descripción:** Implementación práctica de técnicas de visualización de datos utilizando Matplotlib, Seaborn y Pandas. Incluye ejercicios guiados y presentación del capítulo.
- **Tecnologías:** Python, Matplotlib, Seaborn, Pandas, Jupyter Notebook
- **Contenido:**
  - Guía de ejercicios con soluciones propuestas
  - Presentación interactiva del capítulo
  - Visualización de datasets como Wine Dataset

[Ver código →](./proyectos/lab1/Lambda/)

---

### 🌍 Laboratorio 2: Visualización de Asociaciones y Datos Geoespaciales

**Estudio de los Capítulos 12 y 15 del libro _Fundamentals of Data Visualization_.**

- **Ubicación:** [`proyectos/lab2/Lambda/`](./proyectos/lab2/Lambda/)
- **Descripción:** Análisis y visualización de asociaciones entre variables cuantitativas y visualización de datos geoespaciales. Los gráficos generados se utilizaron en una presentación profesional.
- **Tecnologías:** Python, Matplotlib, Seaborn, GeoPandas, Jupyter Notebook
- **Contenido:**
  - Visualización de asociaciones entre variables
  - Visualización de datos geoespaciales (opcional)
  - Dataset: World Happiness Report 2019
  - [Presentación en Google Slides](https://docs.google.com/presentation/d/1Vw3mghhjd8ac2N7EzxAfOL3qCYe625oi1tU_V2jggUo/edit)

[Ver código →](./proyectos/lab2/Lambda/)

---

### 🔤 Laboratorio 3: Encoding de Variables Categóricas

**Implementación de técnicas de encoding basadas en el libro _Python Feature Engineering Cookbook_ de Soledad Galli.**

- **Ubicación:** [`proyectos/lab3/Lambda/`](./proyectos/lab3/Lambda/)
- **Descripción:** Exploración de técnicas de encoding de variables categóricas como One-Hot Encoding y Ordinal Encoding para preprocesamiento de datos.
- **Tecnologías:** Python, Pandas, Scikit-learn, Jupyter Notebook
- **Contenido:**
  - One-Hot Encoding
  - Ordinal Encoding
  - Dataset: Indian Food Dataset

[Ver código →](./proyectos/lab3/Lambda/)
